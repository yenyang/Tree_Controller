# Patch v1.7.0.1
* Reinstated Disable Tree Growth Setting. Changed description. Added Activate and Deactivate buttons with warnings and confirmations.
* Disable Tree Growth setting now when toggled pauses all tree aging by enabling vanilla Decoration component on all trees other than Lumber.
* When Disable Tree Growth is disabled or settings are reset, existing trees are not effected and will continue to have paused tree aging. Use Tree Controller Tool to resume aging for trees.
* Tree Controller tools can now enable/disable vanilla Decoration component depening on Preserve Age toggle without changing a trees age or prefab.
